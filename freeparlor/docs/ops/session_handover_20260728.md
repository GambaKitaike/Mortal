→ **引き戻しは相手分布（pool）より損失側（KL）に置くほうが効く**、が単一変数で示された。

### 1b. 【本セッション最大の発見】損傷もチップ獲得も **最初の 2000 step で完了**

> **⚠ 2026-07-29 追記: この見出しは放銃劣化については保たない。**
> 独立 run（`early_probe_20260728_202533`）で step 0–2000 を再測したところ、
> **放銃劣化は再現せず**（終端 z=+0.16 / 本節の根拠は z=+3.91）、
> **立直シフトと和了率低下は再現した**（立直和了割合は step600 で 78% に到達）。
> よって「最大の発見」と呼べるのは**行動シフトが極めて速いこと**までで、
> 放銃劣化の時間分布は n=1 run の観測にとどまる。
> 正は `../reports/early_damage_probe_result_20260729.md`。

`../reports/anchor_checkpoint_trajectory_20260728.md`（探索的診断・判定非関与）。
init → step2000（全体の **12.5%**）で:

| 量 | Arm K | Arm C |
|---|---|---|
| 放銃 | 11.85% → **13.89%**（z=+3.91） | 11.85% → **14.29%**（z=+4.53） |
| 降りの中断率 | 23.78% → **31.78%** | 23.78% → **37.95%** |
| 立直和了 割合 | 54.32% → **81.24%** | 54.32% → **89.10%** |
| チップ | +0.035 → **+2.85SE（全 ckpt 中の最大）** | +0.035 → **+2.17SE** |

残り 14000 step は「**維持（K）か喪失（C）か**」の期間でしかない
（K: 放銃 z 3.91→2.51 と回復・チップ維持 / C: z 4.53→6.57 と悪化・チップ +2.17→+0.45 と喪失）。

→ **KL アンカーの効能は「初期劣化の防止」ではなく「その後のドリフトの停止」。**
→ **判定1・判定2 を両立する中間 checkpoint は存在しない**（全 ckpt で放銃 z ≥ 2.5）。
  「早期停止して配備」案は成立しにくい。

### 1c. 立直マキシマリズムは **この経済で実際に収支を生む**

Arm K はチップ +0.508枚/半荘（+2.18SE）、素点・順位点・合算も全て + 方向、
avg_rank も init 比 n.s.（わずかに良い）。**和了率・放銃率は悪いのに収支で勝つ**状態が
n=800 で実測された。探索ラダー閉幕時の「本質的機会費用仮説」と整合し、
**0b 議題1（商用採否）の一次材料**になる。

### 1d. 基礎劣化の中身が特定された（新規指標4本）

- **降りの過程**（`analyze_genbutsu_discipline.py`）: 降りの中断率
  init 23.78% → C 49.29% / K 33.75%。**現物保持率はむしろ上昇** ＝
  安全牌が無いのではなく**持っていて使わない**
- **和了の構成**（`diagnose_agari_composition.py`）: 平均和了打点の上昇は
  **全層 n.s. で構成シフト由来**（Simpson 型）。**成果として引用してはならない**
- **和了形**（`analyze_agari_shape.py`）: 役牌絡み init 29.25% → C 11.48% / K 21.39%。
  七対子志向は両腕で有意に増加
- **役牌の切り順**（同スクリプト外の追測、レビュー §5c）: 自風を三元牌より早く切る
  **系統的誤りは init 由来**で K で有意に悪化

### 1e. init 自身の限界も切り分けられた

`../reports/qualitative_review_anchor_c_20260727.md` §5a/§5c:
南暗刻ポン・ポンテン取らず・ダマ→翌巡ツモ切り立直は **init 由来**（PPO の罪ではない）。
**基礎劣化は「完璧な init を壊した」ではなく「不完全な init を更に壊した」**。

**設計上の重要論点**: init は報酬にチップを含むのに天鳳的な立直判断をする。
原因は報酬ではなく**データ分布**（天鳳2009 に「チップのために曲げた人間」が存在しない）。
→ **init を出発点にする限りチップ最適な判断は獲得できない可能性**。
**0b 議題6（次世代訓練方式）の一次材料**。
