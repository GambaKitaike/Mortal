## 2. 新しく分かったこと

### 2a. run 間ばらつきが効果量と同程度（**本セッション最大の発見**）

`early_damage_probe_result_20260729.md` §9。step・n・seed の交絡を全部消した3点比較:

| run | 放銃率 | 差 | z |
|---|---:|---:|---:|
| init（共通基準・n=400） | 12.08% | — | — |
| Arm K step2000 | 14.12% | +2.041pp | **+2.70** |
| プローブ#1 step1900 | 12.19% | +0.116pp | **+0.16** |
| プローブ#2 step2000 | 13.03% | +0.958pp | **+1.32** |

**どの run も外れ値ではなく、連続的に散らばる。**

再現したのは **立直シフト**（両 run とも step200 で 63–67%、終端 75–77%。init 54.29%）と
**降りの中断率の悪化**。**放銃率という結果指標の水準は再現しない。**

→ 前回申し送り §1b の「本セッション最大の発見（損傷は最初の 2000 step で完了）」は、
**行動シフトについては支持、放銃劣化については run 間ばらつきに埋もれる**。

### 2b. eval の SE は保守的だった（判定の結論はすべて強まる）

`check_cluster_se.py`。eval は **1 seed = 1つの山を4回、challenger の座席だけ
ローテーション**する設計で、同一 seed の4半荘は**負に相関**（ICC −0.04〜−0.32）。
現行の半荘クラスタ SE は**過小評価ではなく過大評価**。

| | 現行 | seed クラスタ + 対応あり |
|---|---:|---:|
| Arm K 判定1 放銃 | z=+2.51 | **+3.15** |
| Arm K 判定2 チップ | +2.18SE | **+3.35SE** |
| Arm C 判定1 放銃 | z=+6.57 | **+8.12** |

**判定値は凍結のまま変更しない。** 変わるのは解釈に添える留保で、
「SE が甘いかも」ではなく「**SE は保守的なので結論は少なくともこの強さ**」になる。
なお参考値の訂正が1つ: Arm K の和了率は現行 n.s.（z=−1.69）だが、
より精密な SE では **z=−2.63 で有意**になる。

### 2c. 鳴き判断は両腕とも双方向に壊れている（役で絞っても結論不変）

`policy_quality_metrics_20260728.md` §2/§8a:

| 指標 | init | Arm K | z | Arm C | z |
|---|---:|---:|---:|---:|---:|
| **有役**テンパイ機会の見送り率 | 84.09% | 90.51% | **+5.14** | 96.20% | **+11.11** |
| 取った鳴きのテンパイ率 | 16.72% | 14.00% | **−2.01** | 10.37% | **−3.96** |

役無しテンパイを分母から外しても**差はむしろ拡大**した（K +4.36→+6.42pp）。

### 2d. 牌効率と一貫性は Arm C だけが壊れ、Arm K は init 水準を保存

向聴を外した率 C **z=+22.27** / K n.s.、孤立牌の切り順逆転率 C **z=+5.69** / K n.s.
= **判定指標と独立な牌理側の測定でも「pool より損失側（KL）」が再現**した。

### 2e. 打点ルートは所見と逆（両腕とも init より畳まない）

染め手ルートの放棄率 19.65% → K 18.28%(z=−2.90) / C 16.60%(z=−6.55)。
Gamba の「打点を作らない」という所見と**集計が逆を向いた初めての例**。
ただし指標は頻度であって質ではなく、「意図の頻度は落ちていない」までしか言えない。
**意図と成立の分離が次の測定課題。**

### 2f. 副産物: 暗槓の赤がチップから漏れている（規模は無視できる）

`AgariDetail.num_aka` は暗槓内の赤を数えない（`count_num_aka` は `fuuro_overview` を
見るが暗槓は `ankan_overview`）。`chip_base` がこれを使うので**暗槓の赤にチップが
付いていない**。実測 **0.005枚/半荘** = 判定の効果量の約 1/100 なので既存の結論に影響なし。
経済プリセット（0b 議題2 / G3）を触るときに併せて裁定すればよい。
