## 6. 判定を起草するときに必ず添える留保（`anchored_ppo_design.md` §9 の凍結記載）

1. **run 間ばらつきが効果量と同程度**（`early_damage_probe_result_20260729.md` §9）。
   本再走が「判定1 の閾値を跨ぐか」を1本で決める検出力は限定的である。
   実際 β×4 が動かしたのは放銃 z で 0.30（+2.51 → +2.21）に過ぎず、
   これは同一 config の run 間で観測されたばらつき（step2000 で z=+2.70 / +0.16 / +1.32）より小さい。
   **判定条件は凍結済みなので変更しないが、「β=0.4 では足りなかった」と読むのは過剰**。
   正しくは「**この1本では判定1 を跨げなかった**」
2. **eval の SE は保守的**（`check_cluster_se.py`。seed クラスタ + 両脚対応で 0.77–0.81 倍）。
   したがって放銃劣化の有意性は「少なくともこの強さ」。判定値は現行 SE のまま
3. **L1（最適化衛生）は未修正のままの測定**（`ppo_optimization_health_20260725.md` §5）。
   本 run の実測（`analyze_staleness_decomposition.py`）は
   staleness 平均 **94.4 step**（transit 69.9 + 量子化 24.5）、clip@epoch1 0.2050（lag1）/
   0.2072（lag2）で、Arm K（93.4 step / 0.2153・0.2124）と**同水準**。
   L1 は両 run で同じ状態なので、C/K/b04 の比較には交絡しない
4. 本測定は **kl_beta=0.4 の1点**についてのもの。§6a により**再走はこれで打ち切り**
