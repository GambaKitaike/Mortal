## 4. 起票する診断タスク

1. **方策の一貫性**（東4局の所見）— 同型の牌姿で異なる選択をする度合いの指標化。
   Arm C の「降りを始めて中断する」も同じ族の症状であり、共通の指標にできる可能性
2. **打点を作りに行く手順の指標化** — 七対子決め打ち（Arm C §5e）と
   ホンイツ移行の見送り（本書 §2）は、いずれも「和了率では現れず手順に現れる」型。
   受け入れ・打点の両睨みを測る指標が要る（`teacherfree_training_candidates.md` §2d の
   SP 計算 2フラグと同じ領域）
