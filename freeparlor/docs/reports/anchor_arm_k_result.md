## 2. 判定（§6 の機械的照合。1v3 両脚 n=800、seeds [10000,10200)）

### 判定1（基礎維持）: **不成立**（境界付近）

## 3. 結論部で明示すべき事項

1. **基礎劣化は緩和されたが止まっていない。** 放銃 +1.31pp（z=+2.51）は有意。
   ただし C の +3.60pp から大幅に改善し、和了率・avg_rank の劣化は消えた
2. **経済適応は実在した。** チップ +0.508枚/半荘（+2.18SE）。
   `chip_value=5` の経済で、立直偏重（立直和了 83.35%）が裏ドラ・一発・立直棒を
   収穫する構造。**「和了率も放銃率も悪いのに収支は勝つ」**という状態が実測された
3. **打点上昇は C 同様に構成シフト由来**（`diagnose_agari_composition.py`）:
   全和了 +1017.2点（z=+6.84）だが、層別では立直和了 +87.1（n.s.）/ ダマ −275.7（n.s.）/
   副露 +90.8（n.s.）。**どの層でも有意な上昇はなく、上昇は立直和了 54.32%→83.35%、
   ダマ 21.30%→0.80%、副露 24.38%→15.84% の構成シフトの産物**。
   **「平均和了打点の上昇」を K の成果として引用してはならない**（C と同じ留保）
4. **降りの過程は改善したが init 水準ではない**（`analyze_genbutsu_discipline.py`）:
   降りの中断率 init 23.78% → **K 33.75%**（C は 49.29%）、
   危険牌選択率 40.86% → 47.32%（C は 56.38%）
5. **副露系の資産は部分的に保存された**: 役牌絡み C 11.48% → **K 21.39%**（init 29.25%）、
   副露和了 C 6.53% → **K 15.84%**、**加カンは K で保存**（0.10%、n.s.。C は 0.01% で消滅）
6. **ダマ和了は両腕とも消滅**（init 21.30% → C 0.82% / K 0.80%）。
   **立直マキシマリズムそのものは KL アンカーでも止まらない**

## 4. 解釈上の留保

- **L1（最適化衛生）は未修正のままの測定**。ただし C が失敗し K が半分成功した以上、
  **「両腕とも L1 のせいで効かなかった」という説明は今回の結果には当てはまらない** —
  L1 交絡は「効かなかった場合」の留保であり、K は効いている。
  L1 修正で更に伸びる可能性は残る（未検証）
- 本判定は **kl_beta=0.1 の1点**についてのもの
- レンズ4 で「論外な打ち方が無くなった」という定性評価を得ている一方、
  七対子決め打ち・打点構築の見送り・鳴き機会の取りこぼしは残存（同書 §2）

## 5. 進路

### 5a. 事前登録の再走規定（§6a）が発火する

§6a: 「**判定1✗（アンカー過弱）→ kl_beta × 4 で再走**（最大1回・機械的）」。
K は判定1✗ なので、**kl_beta = 0.4 での再走が事前登録により許容される**（1回限り、
新規 run dir、同一判定条件、その結果が最終）。これは機械的適用であり新規の設計判断ではない。

**実施可否は資源配分の裁定事項**（GPU ~1日 + eval）。実施する場合の期待:
β を上げれば放銃劣化は更に縮む見込みだが、判定2 のチップ獲得（現状 +2.18SE）が
削られる可能性がある（アンカー過強側へ寄る）。

### 5b. 事前登録が覆っていない組み合わせ

`../ops/anchor_c_route_decision_20260726.md` §2 は **C の象限**を軸に書かれており、
「C=IV かつ K=III」は明示的に扱っていない（同書が想定したのは「K も IV なら全滅 → L1」）。
**したがって次の軸の選択は 0b 方針セッションの裁定事項**であり、本判定では決めない
（post-hoc に進路を作らない）。

判断材料として本判定が提供する事実:
- **引き戻しは相手分布（pool）ではなく損失側（KL）に置くべきだった** — 同一の
  「凍結 init を参照点にする」思想でも、置き場所で結果が IV と III に分かれた
- **立直マキシマリズムは β=1・chip×5 の経済で実際に収支を生む**（+2.18SE）。
  これは探索ラダー閉幕時の「本質的機会費用仮説」と整合し、0b 議題1（商用採否）の
  一次材料になる
- **基礎劣化は「相手分布」でも「損失アンカー」でも完全には止まらない**。
  残る候補は L1（最適化衛生）と、`robust_selfplay_ppo_design.md` の L4
