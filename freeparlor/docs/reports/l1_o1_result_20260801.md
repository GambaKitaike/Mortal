## 4. eval 運用で起きた事故（**判定値には影響なし**・要バックログ化）

**参照脚の初回測定が誤った対戦相手で走った。**

- 設計書 §7 の事前登録コマンドは `GRP_BASELINE_CKPT` を**指定していない**
- `eval_grp_baseline_1v3.py:136` の既定値は
  `DEFAULT_BASELINE_CKPT = /home/gamba/mahjong/runs/grp_baseline.pth` で、
  これは **2026-06-20 の DQN 期ファイル（`steps=0`・`current_dqn`/`aux_net` キーを持つ）**。
  一方すべてのラッパ（`run_eval_grp_baseline_1v3_stage3.sh:14`）は
  `GRP_BASELINE_CKPT="${GRP_BASELINE_CKPT:-$INIT_CKPT}"` で init を渡している
- 結果、参照脚だけ未学習相手と対戦し **800半荘中 798勝・avg_rank 1.0025・放銃 0.27%** という
  異常値になった（判定1/2 の2脚は正しい init 相手で測れていることをログで確認済み）
- 正しい相手（`GRP_BASELINE_CKPT=$INIT_CKPT`）で**再測して §3-2 の値を得た**。
  誤測定の成果物は削除せず `aborted_wrongbaseline_*` として run dir に保全
- **defect**: 既定値がどのラッパの実運用値とも異なる。`eval_grp_baseline_1v3.py` は
  baseline パスをログに出すので発見可能だが、**既定値での実行を禁止する（env 未指定なら
  例外で落とす）**のが禁則「サイレントフォールバック禁止」に沿う。
  併せて設計書 §7 のコマンド例に `GRP_BASELINE_CKPT` を追記すべき（§12 に注記済み）
