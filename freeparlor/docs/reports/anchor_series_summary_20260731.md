## 0. 結論（3行）

1. **anchor 系列は基礎技能の劣化を止められなかった**（判定1 は 3 arm すべて不成立）。
2. **しかし経済的な期待値は大きく上昇した** — チップ **+0.4〜0.5 枚/半荘**（K で +2.18SE）、
   3ストリーム合算の点推定で **+3.4〜+3.8 千点/半荘**（有意水準未達 1.2〜1.4SE）。
3. ⇒ **チップありのルールでは、基礎技能（放銃率・和了率）だけで AI の性能を説明できない。**
   **放銃が有意に増え和了が減っているのに、着順は悪化せず収支は改善する**方策が実在した。

## 1. 何を検定したのか

診断（`fundamentals_degradation_diagnosis_20260725.md`）は「PPO は init が持っていた
基礎技能を訓練で壊す」ことを確定させ、原因仮説の主犯を「**アンカー不在**（損失に init への
引き戻しが無い）」、増幅を「自己対戦均衡の退化」と置いた。anchor 系列はこれを
**2つの単一変数 arm** で切り分ける実験だった:

| arm | 介入 | 検証した仮説 |
|---|---|---|
| **C** | opponent pool に凍結 init を 25% で常駐（損失は不変） | 均衡退化の単独犯性 |
| **K** | 損失に凍結 init への masked full KL（pool は不変） | アンカー不在の主犯性 |
| **b04** | K の `kl_beta` を ×4（§6a の機械的再走・**最後**） | K が「アンカー過弱」だったのか |

判定条件（凍結）: **判定1** 放銃率(ckpt−init) の差が半荘クラスタ SE で **z < 2** /
**判定2** チップ/半荘(ckpt−init) が **+方向かつ ≥1SE**。1v3 両脚 **n=800**、
seeds [10000,10200)、argmax・guard ON・自然分布。

## 3. 確定した事実

### 3a. 引き戻しは「相手分布」ではなく「損失側」に置くべきだった

同じ「凍結 init を参照点にする」思想でも、**置き場所で結果が真逆に分かれた**:

- **pool 側（Arm C）は両方を失った** — 基礎劣化は plain PPO より悪化（+3.60pp）し、
  経済適応も消えた（+0.45SE）。素点・順位点は**有意に負**（−2.78 / −2.60SE）
- **損失側（Arm K / b04）は劣化を約 1/3 に圧縮しつつ経済適応を保った**

これは単一変数アブレーションで確定した**順序関係**であり、参照点の中身（牌譜由来か否か）に
依存しない**機構の知見**として持ち越せる（`robust_selfplay_ppo_design.md` §5b）。

**判定と独立な牌理側の測定でも同じ順序が再現した**（`policy_quality_metrics_20260728.md`）:
向聴を外した率は **C だけが壊れ（z=+22.27）K は init 水準を保存**（n.s.）。

### 3b. アンカーの強さ（β）では判定は動かない

β を 0.1 → 0.4 にして `kl_ref_mean`（init からの乖離）は **0.13048 → 0.06895 と約半分**に
なった＝ β は機構として確かに効いている。それでも:

- 判定1 の放銃 z は +2.51 → **+2.21**（閾値 2 を跨がない）
- 判定2 のチップは +2.18SE → **+1.75SE**（成立のまま、やや低下）

**どちらの変化も同一 config の run 間ばらつきより小さい**
（`early_damage_probe_result_20260729.md` §9: 同一条件の放銃劣化が z=+2.70 / +0.16 / +1.32）。
⇒ **「β をもっと上げれば判定1 を満たす」という道は、この系列の設計では検証できない。**
§6a により再走は使い切られており、**ここで閉じる。**

### 3c. 損傷は最初の 2000 step でほぼ完了している

`anchor_checkpoint_trajectory_20260728.md`: 中間 checkpoint の測定で、
**損傷もチップ獲得も最初の 2000 step（全体の 12.5%）でほぼ完了**していた。
残り 14000 step は「維持（K）か喪失（C）か」の期間。
⇒ **KL アンカーの効能は初期劣化の防止ではなく、ドリフトの停止だった。**
判定1・判定2 を両立する中間 checkpoint は存在しない（全 ckpt で放銃 z ≥ 2.5）。

## 4. 本題 — 基礎技能と「性能」の乖離（Gamba 裁定 2026-07-31 の総括）

> **anchor 系列は基礎技能を悪化させたが、EV を大きく上昇させることができた。**
> **チップありのルールにおいて、基礎技能だけでは AI の性能は説明できない可能性を示唆している。**

この総括を支える一次データを、正確な形で並べる。

### 4a. 悪化した基礎技能

| 指標（Arm K / b04、init 基準） | 差 | z |
|---|---:|---:|
| 放銃率 | +1.31pp / +1.15pp | **+2.51 / +2.21**（有意） |
| 和了率 | −1.03pp / −1.19pp | −1.69 / −1.92（n.s.、方向は劣化） |
| 有役テンパイ機会の見送り率 | +6.42pp / +7.08pp | **+5.14 / +5.88**（有意） |
| 降りの中断率 | +9.97pp / +3.70pp | **+12.83 / +4.86**（有意） |
| ダマ和了の消滅（K）/ 打点低下（b04） | 21.30%→0.80% / 打点 −1253点 | — / **−5.07** |

**基礎技能は明確に劣化している。** 定性レビュー（レンズ4）も3 arm すべてで
牌理・鳴き判断の誤りを具体的に指摘しており、定量と方向が一致している。

### 4b. それでも上昇した経済的期待値

| | チップ（枚/半荘） | 千点換算 | 合算（千点/半荘） |
|---|---:|---:|---:|
| Arm K | **+0.507（+2.18SE）** | +2.54 | **+3.835（+1.38SE）** |
| b04 | **+0.405（+1.75SE）** | +2.03 | **+3.430（+1.22SE）** |

- **判定2（チップ）は事前登録の閾値を満たして成立**。K は +2.18SE で 2SE も超える
- **合算の点推定は +3.4〜+3.8 千点/半荘**。半荘あたり 3400〜3800 点は経済的に大きい。
  ただし **1.2〜1.4SE で有意水準には達していない**（素点・順位点の分散が大きいため）。
  **「有意に上がった」と書けるのはチップ、「大きく上がった」と書けるのは点推定**である
- **avg_rank は悪化していない**（K −0.018 / b04 −0.005、いずれも n.s.。方向はむしろ改善）

### 4c. 乖離の中身 — 「和了率も放銃率も悪いのに収支は勝つ」

放銃が有意に増え、和了が減り、鳴き機会を取りこぼし、降りの規律も崩れている方策が、
**着順を悪化させず、チップ収支を有意に改善した。**

機構は `chip_value = 5.0`（チップ1枚 = 5000点相当）の経済にある:
立直に偏重すると**裏ドラ・一発・立直棒**がチップに直結する。
和了の構成は init の 立直 54.32% / ダマ 21.30% / 副露 24.38% から
K で 立直 83.35%、b04 で 立直 71.01% へシフトした。
**打点の絶対水準ではなく「チップが乗る和了の比率」を上げる**のが、この経済での最適化だった。

> **含意（本総括の中心）:** フリー雀荘ルール（β=1・チップ×5）では、
> **放銃率・和了率という古典的な「強さ」の指標が、実際の収支と乖離する。**
> AI の性能をこれらだけで評価する運用は、この経済では成立しない。
> 逆に言えば、**基礎技能の劣化を「性能低下」と読み替えることも誤り**であり、
> 評価は必ず**経済3ストリーム（素点・順位点・チップ）と併記**する必要がある。

### 4d. この含意に必ず付く4つの留保

1. **相手は init 1種のみ。搾取可能性は未検証。** 立直マキシマリズムは「相手が適応しない」
   前提で成立している可能性がある。これを検定するのが **0b 議題3 = 敵対的搾取者訓練**であり、
   **本総括の含意の妥当性はその結果に依存する**（Stage1 判定も同じ限界を明記していた）
2. **合算は有意水準未達**（1.2〜1.4SE）。有意なのはチップ単独（+2.18SE / +1.75SE）
3. **EV 上昇はアンカーが作ったものではない。** plain PPO（Stage1）が既に
   チップ +0.520（n=800 換算で ≈2.2SE）を得ていた。**アンカー（KL）の寄与は
   「チップ獲得を保ったまま基礎劣化を 1/3 に圧縮した」こと**であり、
   pool アンカー（C）は逆に**両方を失わせた**
4. **商用採否とは別問題。** 0b 裁定 §3 議題1 は「鳴き判断と牌理が init 水準に戻るまで否決」で、
   その条件は b04 でも**未達**（有役テンパイ機会の見送り 91.16%）。
   EV が上がることと、製品として出せることは別

## 5. 系列を閉じる（Gamba 裁定 2026-07-31）

**anchor 系列はここで終了する。** 根拠:

- §6a の再走規定は **b04 で使い切った**（「再走後の結果が最終、それ以上の再走禁止」）
- 3 arm すべてで **判定1 は不成立**。アンカーで基礎劣化を止める路線は**このパラメータ空間では尽きた**
- β の効き方（§3b）から、**残っている自由度は β ではない**

### 5a. 持ち越すもの

| | 持ち越し |
|---|---|
| **順序関係の知見**（引き戻しは pool より損失側） | **持ち越せる**（参照点の中身に依存しない） |
| **配管**（ref forward / pool の anchor 分岐 / 検定19・20 / 判定書式 n=800） | **持ち越せる**。アンカーは config のパス指定で差し替え可能 |
| **L2 の次の一手** | `robust_selfplay_ppo_design.md` §3 の **D3（残差方策 `logits = ref_logits + Δ(s)`）** は Arm K の ref 配線をそのまま再利用できる（配線のみ）。β のような量級較正が不要な点で §3b の壁を回避できる可能性がある — **未検証・未登録** |
| **産出された重み**（anchor_c/k/b04 の checkpoint） | **持ち越せない**（天鳳由来 init からの warm-start。0b 議題5） |

### 5b. 閉じることで**開かない**問い

- 「牌譜非依存アンカー（A1/A2/A3）でも同じ保護が出るか」は**別の実験**（16k run 1本）で、
  **現行ロードマップに入っていない**（`robust_selfplay_ppo_design.md` §5c、0b 議題5）
- 「L1 を直せば基礎劣化が止まるか」＝ **次の軸（L1 O1 → O3）**。
  L1 は 3 arm すべてで同水準（staleness 92–94 step）だったので**本系列の比較には交絡していない**が、
  「アンカーが効かなかったのは L1 のせい」の可能性は**排除できていない**

### 5c. 次にやること（0b 裁定 §5 の順序どおり）

1. **L1 O1 発進**（`l1_o1_submit_every_design.md` 凍結済み。実装済み・発進待ち）
2. L1 O3（`ppo_epochs` 4→1）
3. **候補2（敵対的搾取者訓練）** ← **§4d-1 の留保を解消する実験**でもある
4. 候補1（oracle 蒸留）

なお **西入の除去（W1）は O1 の後**（`../design/parlor_rule_west_round_design.md`、
Gamba 裁定 2026-07-31 = W1 + S1）。O1 の baseline が西入ありで訓練された
Stage1-16000 なので、順序を守らないと2変数になる。
