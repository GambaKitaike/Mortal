1. **鳴き判断は両腕とも「双方向に」壊れている** — 良い鳴き機会をより見送るようになり、
   かつ**取った鳴きの質も落ちている**（C はテンパイ率 z=−3.96）。Gamba の所見

   C は向聴を外した率 z=+22.27・切り順逆転率 z=+5.69 に対し、**K は全て n.s. か境界**。

3. **したがって「引き戻しは pool より損失側（KL）」という順序関係は、判定指標
   （放銃・チップ）だけでなく牌理の健全性でも成り立つ**

## 2. 鳴きの質（`analyze_call_quality.py`）

鳴き機会 = `PlayerState.last_cans` が pon/chi/daiminkan を許した決定点。

| 指標 | init | **Arm K** | z | **Arm C** | z |
|---|---:|---:|---:|---:|---:|
| 取った鳴き: 向聴前進率 | 67.72% | 65.81% | −1.17 (n.s.) | 64.32% | −1.53 (n.s.) |
| **取った鳴き: テンパイ率** | 16.72% | **14.00%** | **−2.01** | **10.37%** | **−3.96** |
| **テンパイ機会の見送り率** | 91.54% | **95.89%** | **+7.21** | **98.55%** | **+13.17** |
| **向聴前進機会の見送り率** | 91.13% | **94.34%** | **+9.05** | **97.74%** | **+21.03** |
| 鳴き機会（n） | 26,154 | 24,905 | | 24,982 | |
| 実際に鳴いた（n） | 1,812 | 1,164 | | 482 | |

### 2a. これが新しく言えること

**副露率（init 17.33% → K 10.57% / C 4.02%）は「鳴かなくなった」しか言わない。**
本測定が加えたのは:

- **見送りの選択性が上がっていない。** 「テンパイに取れる鳴き」という最も価値の高い
  機会クラスに限っても見送り率が上がっている（K +4.36pp / C +7.01pp）。
  鳴きを減らした分が悪い鳴きから削られたのではない
- **取った鳴きの質も落ちている。** 鳴いた回数が 1/4 になった Arm C ですら、
  残った鳴きのテンパイ率は init の 16.72% → 10.37%（z=−3.96）。
  「少なく鳴くが良く鳴く」にはなっていない
- Arm C の鳴き前の受け入れは 31.56 枚（init 24.90 枚）＝ **手が広いときにしか鳴かない**
  のに、それでもテンパイ率が低い。鳴きの選び方そのものが劣化している

**Gamba の「鳴き判断は双方向に壊れている」（`qualitative_review_anchor_k_20260728.md`
§5b）は、この2軸で定量的に確認された。**

### 2b. 限界

向聴前進・テンパイ到達は**良い鳴きの必要条件であって十分条件ではない**。
守備・打点を見ていないので、絶対値ではなく init との差分を読むこと。

> **§8a で更新**: 「役無しテンパイになる鳴きも数えている」という限界は
> `yaku.py` で解消した。分母を有役に絞ると **init の絶対値は 84.09% に下がるが、
> 両腕との差はむしろ拡大する**（K +4.36 → +6.42pp、C +7.01 → +12.11pp）。

## 3. 牌効率（`analyze_tile_efficiency.py`）

自分のツモ番の打牌のみ（鳴き直後は食い替え制限のため除外）、自分も他家も立直なし、
向聴 ≤ 3。各候補打牌の (向聴, 受け入れ枚数) を全列挙して選択と比較する。

| 指標 | init | **Arm K** | z | **Arm C** | z |
|---|---:|---:|---:|---:|---:|
| **向聴を外した率** | 0.72% | 0.68% | **−0.65 (n.s.)** | **2.55%** | **+22.27** |
| **受け入れで支配された率** | 14.74% | 14.91% | **+0.70 (n.s.)** | **18.15%** | **+13.35** |
| 平均受け入れ損失（枚） | 4.64 | 4.55 | −1.22 (n.s.) | 4.63 | −0.14 (n.s.) |
| 対象打牌（n） | 67,887 | 65,843 | | 65,819 | |

**これが本書で最も鋭い結果である。**

- **Arm K は牌効率を完全に保存した**（3指標すべて n.s.）
- **Arm C は牌効率そのものを壊した** — 向聴を最大化しない打牌が **3.5 倍**（0.72%→2.55%）

Gamba の「牌理の純粋なミス」（ArmK §5b の 打8m / 打3s / 打6p）という所見は
**Arm K については集計上は再現しない**。K の残る問題は牌理ではなく、
§2 の鳴き判断と、既知の押し引き（降りの中断率 33.75%、z=+12.83）にある。

### 3a. 限界

打点・安全度・他家の動向を一切見ていない。受け入れを捨てて打点を取る正当な選択も
「支配された」に数えるので、**絶対値（init ですら 14.74%）は牌理の巧拙を意味しない**。
意味があるのは差分で、C の +3.41pp は「同じ局面クラスでより受け入れを捨てる方向に
動いた」と読める。

## 4. 方策の一貫性（`analyze_policy_consistency.py`）

| 指標 | init | **Arm K** | z | **Arm C** | z |
|---|---:|---:|---:|---:|---:|
| **孤立牌の切り順 逆転率** | 5.86% | 6.51% | +1.38 (n.s.) | **8.85%** | **+5.69** |
| 不一致率（同一牌姿） | 0.63% | 1.71% | +2.06 | **4.33%** | **+4.99** |
| 切り順ペア（n） | 12,083 | 11,028 | | 9,636 | |
| 同一牌姿の対象決定（n） | 794 | 818 | | 808 | |

**主指標 = 孤立牌の切り順逆転率**: 同じ局で、巡 i に孤立牌 X を切り、そのとき手にあった
孤立牌 Y を後に切ったとき、牌理の価値順（中央ほど高い）に反して score(X) > score(Y) に
なっている割合。`qualitative_review_anchor_k_20260728.md` §5c が役牌で行った
「初打巡目の順序が理論と逆」の測定を数牌へ一般化したもの。

- **Arm C は切り順が有意に乱れた**（+2.99pp、z=+5.69）。Gamba の「6m 切ってるのに
  4m は残す。ちぐはぐ」に対応する
- **Arm K は n.s.**（+0.65pp）。§3 の牌効率と同じ分岐

副指標（同一牌姿での選択のばらつき）は**カバレッジが 3% 程度**（14枚手の完全一致が稀）で
弱い。参考値として併記するにとどめる。なお「手牌+巡目」まで揃えたキーは
再出現が 0 件で測定不能だった。

### 4a. 限界（**これを外すと誤読する**）

**不一致 = 誤りではない。** 方策は手牌だけでなく盤面全体を見ているので、
同じ手牌で違う打牌を選ぶこと自体は正当な文脈依存でありうる。序盤（≤3巡）に絞るのは
この解釈を成立しやすくするための設計にすぎない。読むべきは init との差分。

## 5. 判定との関係（**判定は変更しない**）

本書は判定非関与だが、判定の**解釈**を補強する:

| | 判定指標 | 本書の指標 |
|---|---|---|
| **Arm C** | 放銃 z=+6.57 / チップ +0.45SE = 象限 IV | 牌効率 z=+22.27・切り順 z=+5.69・鳴き見送り z=+21.03 で**全面的に劣化** |

→ **「引き戻しは相手分布より損失側（KL）に置くほうが効く」という単一変数の順序関係が、
判定に使った指標とは独立な牌理側の測定でも再現した。**

同時に、**KL アンカーでも守れなかったもの**が明確になった:

- 鳴き機会の見送り（K でも z=+7.21 / +9.05）
- 取った鳴きの質（K でも z=−2.01）
- 押し引き（降りの中断率 z=+12.83、既測）
- ダマ和了の消滅（既測）

これらは**立直マキシマリズムという均衡そのものの帰結**であり、参照点を置くだけでは
止まらない。0b 議題1（商用採否）・議題6（次世代訓練方式）の材料になる。

## 8. 追補（2026-07-29）— 役判定による分母の厳密化と、打点ルートの測定

§6 が「本書が答えていないこと」として挙げた2件を消化した。

### 8a. 役判定（`yaku.py`）— §6-2 の消化

§2 の「テンパイ機会」は**役の無いテンパイにしか取れない鳴きも数えていた**。
副露手は役が無ければ和了れないので、その機会は**見送るのが正しい**。
`yaku.py` で分母を有役に絞った:

| 指標 | init | **Arm K** | z | **Arm C** | z |
|---|---:|---:|---:|---:|---:|
| テンパイ機会の見送り率（全） | 91.54% | 95.89% | +7.21 | 98.55% | +13.17 |
| **うち有役テンパイ機会の見送り率** | **84.09%** | **90.51%** | **+5.14** | **96.20%** | **+11.11** |

**分母を締めたら差は縮まるどころか拡大した**（K +4.36 → **+6.42pp**、
C +7.01 → **+12.11pp**）。init の絶対値が 91.54% → 84.09% に下がったのは
「役無しテンパイ機会」が約 7pp あった分で、それを除いても
**両腕は本当に和了れる鳴きをより見送っている**。§2 の結論は弱まらない。

**検証**: `python yaku.py --validate <game_logs...>` で eval 牌譜を再生し、
**実際に起きた副露和了 4,608 件すべて**を判定 → **偽陰性ゼロ**。
実際に和了れた手には役があったはずなので、これが役判定器の陽性対照になる。
海底・河底・嶺上・搶槓（巡目の運であって手の形ではない）による和了 30 件は
母集団から除いた。門前和了 15,559 件は本モジュールの対象外。

検証の過程で偽陰性が3段階で潰れた。**いずれも役判定そのものではなく
「母集団の選び方」の誤り**だった点を記録しておく:
79 件 → **暗槓のみの手を副露手と数えていた**（暗槓は門前を維持する）→
6 件 → **海底・河底を状況役として除いていなかった**（1局の tsumo は
実測でちょうど 70、流局 222/222 件で確認）→
1 件 → **嶺上開花の検出が `dora` イベントに割り込まれていた**
（`ankan → dora → tsumo` で直前が槓に見えない。`reach_accepted` が鳴きを
隠していたのと同じクラスのバグで、同じ `TRANSPARENT_EVENTS` で解決）→ **0 件**。

| ドラ切り率（非ドラの選択肢あり） | 2.13% | **1.76%** | **−2.30** | **1.64%** | **−3.18** |
| 対象打牌（n） | 92,404 | 89,186 | | 88,787 | |

**両腕とも init より「打点ルートを畳まない」方向に有意に動いている。**

### 8c. 【重要】定性所見と集計が逆を向いた

これは §2/§3/§4 と違い、**Gamba の所見と集計が同方向を指さなかった**初めての例である。
`qualitative_review_anchor_k_20260728.md` §5a が記録した方法論上の教訓
（**1半荘の所見と集計が食い違うときは、集計を疑う前に標本サイズを疑う**）が
そのまま当てはまる可能性が高い。ただし本指標の側の限界も併記しておく:

1. **粗い代理指標である。** 染め手の「現実的」は枚数だけで判定しており
   ターツの形を見ていない。ドラ切り率は「ドラを含むターツの解体」を数えていない
2. **頻度であって質ではない。** 「ドラを持ち続ける」ことと「ドラを活かして
   打点を作る」ことは別で、前者だけなら**ただ抱えて和了れていない**可能性がある。
   実際 和了率は下がっている（K 19.57% / C 17.69% vs init 20.60%）
3. → 現時点で言えるのは「**打点ルートに乗る意図の頻度は落ちていない**」までで、
   「打点を作れている」ではない。**意図と成立の分離**が次の測定課題

なお染め手が現実的だった打牌の件数は init 20,710 に対し **Arm C 17,248**
（K 19,411）と減っている。C は立直和了 92.7% に寄っており、
そもそも染め手方向の手牌になる局面自体が減っている構成差である。
