## 2. 所見が指標で裏づけられたもの

### A. 鳴きの取りこぼし — **系列で最も強い再現**

Gamba は 3 局で「なぜ鳴かないのか」を指摘した。**すべて役牌絡み**である:

- 東2局3本場 1巡目 北スルー — **この局の自風は北**（実データで確認）。ドラ1（ドラ = 3s、手に1枚）。
  鳴けば自風の役が確定する
- 東4局 4巡目 打發（發対子落とし）— 「發鳴かないとこの手は間に合いません」
- 南3局 3巡目 發スルー — **すでに中をポン済み**。7巡目 1s スルーは
  「鳴いたらホンイツ役牌のテンパイ」

**有役テンパイ機会の見送り率 84.09% → 94.97%（z=+9.91）** がこれを直接裏づける。
`policy_quality_metrics_20260728.md` の Arm C / K と同じ向きで、**O3 でも鳴き判断は
双方向に壊れている**（見送りが増え、かつ取った鳴きのテンパイ率も 16.72% → 8.48% に低下）。

> **Gamba の問い「これがチップありルール特有の戦術なのかな？」への回答: いいえ。**
> チップは赤5 に紐づく経済で、北ポンは赤の獲得枚数を変えない。かつ当該局の
> **北は自風**なので、鳴けば役が付く純然たる前進機会である。所見 A の一例と読むのが妥当。

### B. 役牌の対子・暗刻を自分から落とす — **新しい指標を作った**

既存指標では捕まらなかった（`analyze_ankou_pon.py` は「暗刻**から**ポン」= 鳴いた側、
`analyze_call_quality.py` は鳴き機会が発生した決定点しか見ないので、
**機会が来る前に自分で捨てて機会を消したケース**を取りこぼす）。

新設: `freeparlor/scripts/analyze_yakuhai_retention.py`（read-only・GPU 不要）
- 分母 = **早巡（turn ≤ 6）かつ自他とも立直なし**の打牌決定点で、役牌
  （三元牌 ∪ 場風 ∪ 自風）の対子/暗刻を持っていた件数 — **降りのための役牌落としは除外**
- 分子 = そのうち実際にその役牌を打った件数

**役牌対子を落とした率 1.28% → 3.10%（+1.82pp、z=+9.25）= 2.4 倍。**
暗刻落としは 1.48% → 2.47%（z=+1.70）で**方向は一致するが有意でない**
（機会が 1,134 件しかなく検出力が足りない）。

陽性対照として、レビュー対象の牌譜1本を単体で通すと
**対子落とし2件・暗刻落とし1件**を検出した（= 東4局の發、東3局の西）。
東3局の自風は西であることを実データで確認済みで、Gamba の
「自風の概念を理解していないのか」は指標上も裏づけられる。

### C. 降りの牌選択

東1局 19巡目 打9m（現物 7s を持ったまま）は、
**押し込み率（現物保持時）32.66% → 44.68%（z=+19.21）** と
**降りの中断率 23.78% → 38.16%（z=+18.60）** に対応する。
`early_damage_probe_result_20260729.md` §9 で「降りの規律の悪化は再現する」とされた
所見が、O3 でも同じ向きで出ている。

## 3. 所見と指標が**食い違った**もの（要記録・§3(4) の要求）

### D. 牌理 — 個別指摘は正しいが、集計は劣化を示さない

Gamba は 3 つの具体的な牌理ミスを挙げた（東3局 1巡目打南、東4局 9巡目打7s、
南1局 9巡目打9s）。しかし集計指標は逆を示す:

- **受け入れで支配された率 14.74% → 13.34%（z=−5.83）= 改善**
- **孤立牌の切り順 逆転率 5.86% → 5.30%（z=−1.24）= 有意な悪化なし**
- 向聴を外した率のみ 0.72% → 1.03%（z=+5.21）と悪化だが、**絶対量は 1% 未満**

**乖離の解釈（断定しない）**: 指摘の中身は
「3m 切りのほうが**ピンフになりやすい**」「8s のほうが**安全度的にも**受け入れ的にも良い」
のように**打点・安全度を含んだ複合判断**である。一方 `analyze_tile_efficiency.py` は
明示的に「打点・安全度・他家の動向を一切見ていない純粋な受け入れ比較」であり、
**同じものを測っていない**。よって「Gamba が誤っている」でも「指標が誤っている」でもなく、
**当該領域は未計測**と読むのが正しい。

→ **診断タスクを起票**（§5-1）。

### E. 良い点が計測できていない

Gamba は**良い**判断も 4 箇所で明示した（東1局 15巡目 打東 = イーシャンテンからの降り、
東2局1本場 10巡目 打4p / 東4局 12巡目 打2s / 南3局 8巡目 打7s = **七対子とメンツ手の天秤**）。
とくに七対子との天秤は3局で言及されており、**壊れていない能力**として重要だが、
対応指標が存在しない。

→ **診断タスクを起票**（§5-2）。「劣化の指標」ばかり作ってきたため、
**保たれている能力を検出する指標が無い**という計装上の偏りが露呈した。

## 4. 判定への含意（判定は別タスク・本書は関与しない）

O3 は判定2（経済）で系列最良（チップ +0.639 枚/半荘、合算が init 超え）だったが、
**鳴き判断と降りの規律は Arm C / K と同じ向きに壊れたまま**である。
0b 裁定 §3 議題1（立直マキシマリズムの商用採否）の否決条件は
「**鳴き判断と牌理が init 水準に戻るまで**」であり、
本レビューの A・B・C は**その条件が O3 でも満たされていない**ことを示す。
一方 D（牌理のうち受け入れ部分）は init 以上であり、条件の後半は部分的に満たされている。

## 5. 起票する診断タスク

1. **打点・安全度を含んだ打牌評価の計装（未計測領域）**
   現行の `analyze_tile_efficiency.py` は純受け入れのみ。Gamba の牌理所見は
   ピンフ性・安全度・打点を含む複合判断であり、対応指標が無い。
   材料は既にある（`hand_value.py` の確定打点、`analyze_genbutsu_discipline.py` の現物判定、
   `shanten.py` の形別分解）。**優先度: 中**（0b 議題1 の再検討条件に直結するため）
2. **「保たれている能力」の指標（七対子とメンツ手の天秤）**
   七対子ルートを正しく選べているかの検出。`shanten.py` は既に形別（通常/七対子/国士）の
   向聴分解を持つので、「七対子向聴 < 通常向聴 の局面で七対子を選んだ率」等が安価に作れる。
   **優先度: 中**
3. **役牌暗刻落としの検出力不足**
   z=+1.70 は機会 1,134 件では判定不能。他 run（O1 / Arm C / K / b04）にも同指標を掛けて
   横断で見るのが安い。**優先度: 低**（GPU 不要・既存牌譜のみ）
