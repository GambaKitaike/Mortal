## 3. 結論部で明示すべき劣化（`CLAUDE.md`「基本指標を表に載せるで終わらせない」）

1. **基礎技能は有意に劣化した。** 放銃 +3.60pp（z=+6.57）、和了 −2.91pp（z=−4.78）、
   avg_rank +0.171（z=+3.02）、ラス率 +7.50pp（z=+3.33）。
   **凍結 init を相手の 25% に常駐させても基礎劣化は止まらなかった。**
2. **放銃増の主因は「門前・非立直」の局面**（レンズ4 の突き合わせで新規測定）:

   | 状態 | init | anchor_c | 差 | z |
   |---|---:|---:|---:|---:|
   | 放銃 全体 | 11.85% | 15.45% | +3.60 | +6.57 |
   | うち 立直後 | 3.42% | 5.53% | +2.11 | +6.33 |
   | うち 副露後 | 2.15% | 0.58% | −1.57 | −8.58 |
   | うち **それ以外（門前ダマ）** | 6.28% | 9.34% | **+3.06** | **+7.04** |

   立直後・副露後の放銃「率」は不変（z=+0.61 / +1.00）で、増加は**露出量**（立直率
   1.5倍）と**門前局面の押し引き**による。放銃**打点**も不変（+43、n.s.）＝
   「大物手に振る」のではなく「振る場面が増えた」。
3. **「平均和了打点 +1137.8点（z=+7.72）」を成果として引用してはならない。**
   層別すると立直和了 −147.5（n.s.）/ ダマ +708（n.s.）/ 副露 +288（n.s.）で
   **どの層でも有意な上昇はない**。上昇の全量は構成シフト（立直和了 54.3%→92.7%、
   ダマ 21.3%→0.8%、副露 24.4%→6.5%）による Simpson 型の合成効果
   （`qualitative_review_anchor_c_20260727.md` §2b）。
4. **加カンが実質消滅**（0.14%→0.01%、z=−3.07）。暗カンは不変。
5. **メタ対決**（anchor_c-16000 vs init×3、400半荘）: 素点 −6.913±0.796 は理論ミラー値
   −5 から下振れ。チップ +0.020±0.245（n.s.）。

## 4. 解釈上の留保

- **L1（最適化衛生）は未修正のままの測定**（`ppo_optimization_health_20260725.md`）。
  clip が到着時点で 0.20–0.33、`minibatch_size` 不発、staleness lag 1–2。
  **「C が効かなかった」ことから「pool 是正が無効」を直ちに結論できない** — L1 由来の
  可能性を排除できない。この留保は Arm K の判定にも同じくかかる
- 本判定は「anchor_prob=0.25 の1点」についてのもの。**確率を上げれば違う結果になる
  可能性は否定しない**（§6a により Arm C の再走はしない＝この系列では追わない）
- レンズ4 で init 自身にも弱点が確認されている（南暗刻ポン・ポンテン取らず・
  ダマ→翌巡ツモ切り立直、および天鳳データ由来のチップ非最適な立直判断）。
  **基礎劣化は「完璧な init を壊した」ではなく「不完全な init を更に壊した」**である
